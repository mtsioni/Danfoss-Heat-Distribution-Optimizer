        \begin{abstract}
            \vspace{0.3cm}   
            The Danfoss company had commissioned a team of young Software developers to design an application that optimizes schedules for production unit schedules cost-effective. This application should include multiple aspects, like the maintenance of the units or different heating periods. 
            In this report the developer teams explain how they achieved their result for this specific request. 
            How they managed the program development, using SCRUM as main management framework and GitHub coding platform. 
            And also how they improved, not only their coding skills, but also to work as a team by find solutions for both, technical and social, challenges and improve together
