The product was developed successfully and achieved its main goal.

Major discoveries show that automatic hourly scheduling can significantly reduce operating costs. The system responds to electricity price fluctuations and enables profit from specific situations (e.g. negative electricity prices), when it incorporates a gas motor and an electric boiler in the heat and electricity scenario. An architecture based on \acrshort{mvvm} pattern and Avalonia \acrshort{ui} proved to be an effective choice for parallel development of the frontend and backend.

The developed product solved the problem of inefficient and time-consuming manual scheduling. By automating complex calculations, the system delivers the optimal configuration of active units. This way, the human factor is completely removed, reducing the time needed to create a schedule with a focus on minimal expenses and maximal profit.

Regarding the set goals, the team did not fully cover the system logic with unit tests due to the selected architecture. Isolating individual components for unit testing was technically demanding. Therefore, the team reconsidered their strategy and focused on integration and functional tests instead.

Areas for future work include reducing dependency on static classes and using a centralised database instead of \acrshort{json}/\acrshort{csv} files. This would address issues with manual configuration of file paths. The system could include an \acrshort{api} for direct loading of prices from energinet.dk and a meteorological \acrshort{api}, as demand depends on the weather. Additionally, displaying the units differently to provide an efficient overview with a larger number of available units could be implemented. This demonstrates that the application has great potential for future development.
