Overall, the Software Development result of this project has been a success.
 
The project requirements for a heat Optimizer Distribution application were:

\begin{itemize}
\item Developing a System application that computes cost-effective schedules for production Units, including the possibility of maintenance for the units. 
	
\item The system logic should be based on the Models: Optimizer, AssetManager, SourceDataManger, ResultDataManager, DataVisualizer 

\item  A GUI should allow the user to select maintenance, switch between summer and winter period, include an overview of active units and visualising selected Data within a Graph.

\end{itemize}

All those features had been implemented into a fully functioning application.

But there can still be made further improvements in the future. 
Displaying the units differently, to ensure an efficient overview even with a higher number of units or extending the application to be used over multiple cities. 
Those changes would improve flexibility. 
Implementing an API would upgrade the Data Management.
This shows that this application still has a lot of potential for future development.
