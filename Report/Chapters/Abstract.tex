\section*{Abstract}


The following report explains the development process of the Danfoss Optimizer application, while focusing not only on the application progress, but also on the progress of improving as a team in a Software development process. 

The application request had been, to develop an application that provides cost-effective time schedules for heating units for a certain time window. 
The calculation of those time schedules should take settings, like summer/winter period, change of heat demand and electricity price per hour, in account. 
Additionally, Units should be able to be taken out of commission for maintenance for a selected number of hours. 

For the settings, graphical display of selected Data and Unit information, there should be a Viewport for the User to interact with the application.
For the organization the project processes the developer team used SCRUM and GitHub as programming platform.
